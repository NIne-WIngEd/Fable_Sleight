# Yeviene / Sleight AI website

The company website is maintained on `Rayan/yeviene-website`. GitHub Pages serves the root of this branch at https://nine-winged.github.io/Fable_Sleight/.

The repository's existing project documents and original comic are preserved. The website's separate vision story is at `/Fable_Sleight/vision/`.

## Edit and preview

- `index.html`: product explanation, ownership, progress and contact.
- `assets/site.css` and `assets/site.js`: layout, motion and product-flow illustration.
- `vision/`: the product-vision comic with Yeviene framing.
- `.nojekyll`: serves the static files directly without a Jekyll build.

Serve the repository root with any static HTTP server. No dependencies or build step are required. Push website changes to `Rayan/yeviene-website` to publish them. Keep the canonical and Open Graph URLs in `index.html` aligned with the public website URL.

This is a company website and illustrated product vision. Sleight AI is still in development. The product-flow illustration and comic are not a working product demo.

There are no analytics, forms, uploads, external fonts or third-party scripts. The contact link opens the visitor's email application.
